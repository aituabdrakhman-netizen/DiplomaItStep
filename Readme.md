# FitTracker

## Описание проекта

FitTracker — это консольное приложение, разработанное на языке Python. Оно позволяет пользователю вести персональный фитнес-дневник, сохранять тренировки, отслеживать изменения веса, устанавливать цели и просматривать статистику.

## Возможности программы

- Регистрация нового пользователя.
- Авторизация по логину и паролю.
- Добавление тренировок.
- Просмотр списка тренировок.
- Добавление текущего веса.
- Просмотр истории веса.
- Установка личной цели.
- Просмотр установленной цели.
- Просмотр статистики.
- Сохранение данных в формате JSON.

## Используемые технологии

- Python 3
- JSON
- Visual Studio Code

## Как запустить программу

1. Откройте проект в Visual Studio Code.
2. Запустите файл `main.py`.
3. Зарегистрируйтесь или войдите в существующий аккаунт.
4. Пользуйтесь функциями FitTracker.
